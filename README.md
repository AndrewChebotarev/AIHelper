## 🎯 Project Description

**AIHelper** is a desktop application for working with neural network models via the Ollama API. The program provides a unified interface for interacting with and managing various AI models in a local environment.

## ✨ Features

- **Multi-model support** — work with various neural network models through a single interface
- **Local operation** — complete independence from cloud services via Ollama
- **User-friendly interface** — intuitive management of dialogs and model settings
- **Flexible configuration** — customize generation parameters for each model
- **Interaction history** — save and manage previous dialogs

## 🛠 Technologies
Platforms and languages ​​used:
- **Framework: Avalonia UI**
- **Programming language: C#**
- **Backend: .NET 8**
- **AI integration: Ollama API**
